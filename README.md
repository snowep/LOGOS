# LOGOS - Logical Operational Grid for Intelligent Systems

A JARVIS-like assistant for managing your markdown-based knowledge base with AI-powered capabilities.

## Overview
LOGOS is designed to help individual power users manage their personal knowledge base (similar to Obsidian vault) with a combination of chat interface and AI agents that can perform predefined workflows.

## Features
- Text chat interface for interaction
- CRUD operations on markdown files
- AI-powered workflows for knowledge management
- Real-time synchronization with external file changes
- Built with React.js and Material UI (latest version)
- Node.js/Express backend
- Localhost deployment (no authentication)

1. Clone this repository
2. Install dependencies (see package.json files)
3. Configure your markdown vault path
4. Start the development servers
5. Access at http://localhost:3000
