## Product completion

LOGOS is complete when it can:

1. understand natural-language requests,
2. maintain continuity,
3. retrieve relevant information,
4. assemble context,
5. manage Markdown knowledge,
6. maintain durable memory,
7. manage projects/tasks/decisions,
8. coordinate agents,
9. run councils,
10. execute authorized actions,
11. verify results,
12. automate recurring work,
13. schedule future work,
14. evaluate itself,
15. improve workflows safely,
16. preserve user control.

## Explicitly not required

- voice-first operation,
- camera/vision-first operation,
- humanoid avatar,
- futuristic HUD,
- uncontrolled self-modification.

## Required

- persistent text interaction,
- knowledge continuity,
- tool use,
- memory,
- vault management,
- agent management,
- councils,
- automation,
- evaluation,
- safety,
- verification.

Measure progress by real end-to-end workflows, not number of screens.
